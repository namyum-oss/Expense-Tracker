# Expense Tracker

A simple command-line expense tracker built using Python. This project allows users to record expenses, view transaction history, and calculate their total expenditure.

## Features

- **Add Expenses:** Record an expense with its description, amount, and category.
- **View All Expenses:** Display all previously recorded expenses.
- **Calculate Total Expenditure:** Calculate the sum of all recorded expenses.
- **Menu-driven Interface:** Navigate through the application using a simple command-line menu.

## Technologies Used

- Python 3
- Lists
- Dictionaries
- Loops
- Conditional Statements
- User Input and Output

## How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd expense-tracker
   ```

3. Run the application:

   ```bash
   python3 expense_tracker.py
   ```

## Current Limitations

- Expenses are stored in memory and are lost when the application closes.
- Input validation and category-based filtering are not yet implemented.

## Learning Objective

This project was built to practise Python fundamentals, particularly data structures, loops, conditional logic, and basic application development.
